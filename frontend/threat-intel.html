Threat Intelligence

How this project defines and classifies network threats.

BENIGN

Normal, legitimate network traffic with no indicators of scanning, exploitation, or unauthorized access. This is the baseline the XGBoost classifier was trained to recognize from the CIC-IDS2017 dataset's labeled benign flows.

SUSPICIOUS

Traffic patterns consistent with reconnaissance or automated/unauthorized activity that is not yet confirmed as an active attack — it warrants investigation but isn't treated as proven malicious.

PortScan Bot

MALICIOUS

Traffic consistent with an active attack against the network or a host on it — the highest-priority category for analyst response.

DDoS DoS attacks Brute Force SQL Injection XSS Infiltration Heartbleed

Why the classes are grouped this way

The original CIC-IDS2017 dataset labels traffic with over a dozen specific attack types. This project collapses them into three classes so the XGBoost model predicts a severity tier rather than trying to name the exact attack — reconnaissance-style activity (PortScan, Bot) is grouped as SUSPICIOUS, while traffic that represents an active exploit or attack (DDoS, DoS, Brute Force, SQL Injection, XSS, Infiltration, Heartbleed) is grouped as MALICIOUS.

The AI SOC report you see on the Incident Analysis page uses this same classification, plus MITRE ATT&CK context retrieved via FAISS, to explain why a given flow was placed in one of these three tiers — not just the label itself.
